# מנתב פניות הציבור

אב־טיפוס של צ'אט פתוח לניתוב פניות בנושאי בנקאות. הפונה כותב במילים שלו במה מדובר. סורק מילות מפתח מזהה את סוג הפנייה ואת השלב שבו הפונה נמצא, ומפנה אותו לערוץ הנכון: נציבות התאגיד, פורטל הפיקוח על הבנקים, מסלול דחוף, תחום האסדרה או גוף אחר. כשאין בטקסט מספיק מילות מפתח, הפונה מופנה לערוץ הכללי של היחידה לפניות הציבור.

**הדגמה חיה:** https://itayfurman.github.io/inquiry-router/

זהו אב־טיפוס ולא אתר רשמי של בנק ישראל. הערוצים ופרטי הקשר נלקחו מהמידע הציבורי באתר בנק ישראל בנובמבר 2026.

## מבנה המאגר

| תיקייה | תוכן |
|---|---|
| `demo/` | גרסת ההדגמה, עם תווית אב־טיפוס ומתג "מצב הצגה". היא מוגשת ב־GitHub Pages מהענף `gh-pages` |
| `production/` | חבילת ההשקה לצוות האתר: קבצי הרכיב, הוראות שילוב, הגדרות ובדיקת ניתוב. ההוראות נמצאות ב־[`production/README.md`](production/README.md) |

את חבילת `production/` יש לארח בדומיין רשמי בלבד.

## בדיקת ניתוב

```bash
node production/tests/run-tests.js
```

הבדיקה מריצה 24 שיחות לדוגמה ומשווה כל אחת ליעד הצפוי.

## פרטיות

כל הסריקה והניתוב רצים בדפדפן. אין שרת, אין קריאות רשת, אין עוגיות ואין אחסון, והטקסט שהפונה כותב לא נשמר ולא נשלח.
